DECISION

Bulk conversion creates eligible new clients. Existing or ambiguous matches remain available through individual review and the existing bulk Reconcile action. This avoids silently choosing an advertiser identity. No publication or payment is triggered.

Verification

Production inspection is source-only through registered FleetOps read. Actual WordPress creation on production remains a post-shipping acceptance step. Code rollback restores prior files/build and preserves created client/profile/audit records; no automatic deletion. Expired/changed reviews require a new preview; already-converted leads return their existing client. Test busy locks, selected duplicate contacts, token expiry/tampering, permission changes and WP success then CRM failure then edited/new-preview retry. MySQL row-lock concurrency is a shipment acceptance check; SQLite cannot establish it.
